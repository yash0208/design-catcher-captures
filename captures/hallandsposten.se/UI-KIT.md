## UI-KIT.md

### Recommended Stack

*   **shadcn/ui**: For foundational UI elements like buttons, cards, and navigation menus, providing accessibility and theming capabilities.
*   **Swiper**: Explicitly identified for carousels, offering robust and flexible linear carousel functionality for content sliders.
*   **Tailwind CSS**: To apply the extracted design tokens (colors, typography, spacing, radius) and build custom layouts efficiently.
