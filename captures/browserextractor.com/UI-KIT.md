## UI-KIT.md

### Recommended Stack

*   **shadcn/ui**: For foundational UI components such as buttons, cards, navigation, and form inputs. It provides a robust, accessible, and highly customizable base that integrates seamlessly with Tailwind CSS.
*   **Framer Motion**: Essential for implementing the detected CSS animations (`rise`, `ht-tag-in`, `ht-type`, `hero-recede`) and other dynamic interactions, especially for scroll-triggered reveals and text effects.
*   **21st.dev**: To quickly scaffold complex, visually rich sections like the Hero and Pricing pages, leveraging their curated layouts and integrated motion.
