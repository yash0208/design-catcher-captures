## UI-KIT.md

## Recommended Stack

*   **shadcn/ui**: Provides foundational UI components like Buttons, Inputs, Cards, Navigation Menu, and Accordion, which are essential for the site's structure and interactive elements.
*   **Magic UI**: Ideal for implementing the detected infinite horizontal scrolling marquees for logos and other content strips.
*   **Framer Motion**: Recommended for handling scroll-triggered animations and more granular control over transitions (e.g., opacity and transform animations within tabbed sections), enhancing the user experience.
