## Overview

The Foresight website presents a modern, clean, and professional aesthetic, characterized by a high-contrast black and white palette with minimal use of a vibrant red accent. The design leverages a strong typographic hierarchy using the "Uncut Sans" typeface, emphasizing readability and a contemporary feel. Layouts are spacious, utilizing generous padding and section breaks to create clear content separation. The site employs a dark mode by default for many sections, creating a sophisticated and focused user experience.

**Key Characteristics:**
*   **High Contrast:** Predominantly black (`{colors.surface-dark}` — #000000) and white (`{colors.text-on-dark}` — #ffffff) color scheme.
*   **Modern Typography:** Exclusive use of "Uncut Sans" for all text, with varied weights and sizes establishing clear hierarchy.
*   **Generous Whitespace:** Significant vertical and horizontal padding, especially `{spacing.section-lg}` — 144px, creating an airy feel.
*   **Minimalist Accent:** A single, bold red (`{colors.brand-accent}` — #ff0000) is used sparingly for emphasis.
*   **Subtle Depth:** Absence of explicit box shadows, relying on color contrast and background variations for visual separation.
*   **Rounded Elements:** Moderate use of rounded corners, primarily `{rounded.md}` — 8px, for interactive elements like input fields.
*   **Content-Focused Layouts:** Sections are clearly delineated, often with full-width backgrounds, to highlight content blocks.
*   **Responsive Design:** Defined breakpoints for mobile, tablet, and desktop ensure adaptability.

## Colors

### Brand & Accent
*   **Brand Accent** (`{colors.brand-accent}` — #ff0000): Used sparingly for emphasis, potentially for links, call-to-action highlights, or error states.

### Surface
*   **Canvas** (`{colors.canvas}` — #ebebeb): The primary background color for the overall page body.

## Typography

### Font Family
The primary typeface is "Uncut Sans", a modern sans-serif font, used across all headings, body text, and UI elements. It is consistently paired with the generic `sans-serif` fallback. A single instance of `"Inter var", sans-serif` is noted, likely for a specific system-level UI element or a fallback for certain contexts, but "Uncut Sans" dictates the overall typographic voice.
