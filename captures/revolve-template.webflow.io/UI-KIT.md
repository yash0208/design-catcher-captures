## Recommended Stack

*   **shadcn/ui**: For foundational UI components like buttons, navigation, input fields, and general-purpose cards. This provides a solid, accessible, and customizable base.
*   **Framer Motion**: To implement the detected scroll-triggered reveal animations and general CSS transitions for a dynamic user experience.
*   **21st.dev**: For high-level, opinionated section layouts such as the Hero and Testimonials, which can accelerate development of these common page blocks.
