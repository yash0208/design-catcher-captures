## UI-KIT.md

## Recommended Stack

*   **shadcn/ui**: For foundational UI elements like buttons, navigation, cards, and form inputs. The site uses standard interactive components that align well with shadcn's accessible and customizable primitives.
*   **Aceternity UI**: To achieve the modern, visually engaging hero section. The main headline's style and the overall dark aesthetic with subtle background effects suggest components like `Hero Highlight` and potentially `Background Beams` or `Spotlight`.
*   **21st.dev**: For specialized, ready-made sections like the pricing table. The "Simple, Transparent Pricing" section directly maps to a common `21st-pricing` pattern.
*   **Framer Motion**: To implement scroll-triggered reveal animations and enhance interactivity. The detected `fadeIn` CSS animations and general dynamic feel of the page are well-suited for `framer-motion-scroll`.
*   **Tailwind CSS**: As the primary styling utility framework, leveraging the detected spacing, colors, typography, and radius values from the extraction data.
