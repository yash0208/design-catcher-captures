## UI-KIT.md

### Recommended Stack

*   **shadcn/ui**: For foundational UI elements like navigation menus, buttons, and content cards, providing accessibility and theming capabilities.
*   **Framer Motion**: Essential for replicating the detected scroll-triggered animations and adding dynamic, interactive elements throughout the page.
*   **Magic UI**: For the infinite scrolling logo strip, providing an efficient and visually appealing solution for displaying partner logos.
*   **21st.dev**: To provide a structured starting point for the hero and testimonial sections, leveraging pre-built layouts.
